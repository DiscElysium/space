运行
完整解压文件夹，双击 SPACE-Creative.exe。电脑键盘与鼠标操作。
右下角菜单打开创意工坊，可载入 ARC、LOOM 或九块空甲板。
ARC 为集中仓储布局；LOOM 为纵贯主干线布局。两艘都只有一套完整生产系统。
每个槽位分别保存，切换前自动保存。恢复预设会先要求确认。

无限资源
背包中的材料与设备不限量，科技预先解锁，方便反复建造。
矿点持续补充。预设只给铁矿、石油、红石三种原料配置无限补给仓。
钢材、弹药与科研点仍通过真实生产获得，设备油箱、库存、物流吞吐、控制和碰撞仍按游戏规则运行。
菜单中的“无限原料源”可关闭补给仓自动补满，便于观察真实消耗与断供。
也可以选中自己的储存柜，将其设为任意物料补给源。

完整流程
两种采矿设备 → 混合采矿汇流仓 → 按出口过滤分为铁矿、石油、红石。
铁矿 + 石油 → 基础熔炉 / 快速熔炉 → 钢材汇流仓 → 分配器。
钢材支路一 → 弹药工作台 → 弹药缓存 → 舰艏机炮。
钢材支路二 + 红石 → 实验室 → 科研点。
钢材支路三 → 设备建造储备 → 背包制作全部 16 种设备；储备柜连接装卸器。
石油总仓 → 前部燃油支干 / 双路动力支干 → 重型主推与六台常规机动推进器。
铁矿总仓 → 加工、制造、动力三个维修区。外沿甲板仍可继续手动修复或扩建维修网。
传送桥负责跨线运输，原料不会在交叉处混合。

操作
WASD 平移；Q/E 由成对推进器产生转向力矩。
Space 按住机炮开火，鼠标瞄准；F 按住采矿光束。
B 打开背包；R 旋转；Ctrl+Z 撤销；建造模式中 Tab 切换 2D / 3D。
菜单可定位“设备建造储备”，并查看当前预设、组件和补给仓数量。
选中仓库会显示其系统用途，例如燃油总仓、钢材汇流仓或弹药缓存仓。

修改预设
所有设备和线路都可在游戏中编辑。保留必要的机动对称与重推双路供油。
预设柜子使用了定向出口配置。改接出口时，可在菜单中点击“开放选中柜出口”。
断供后设备可能继续消耗内部余量；这属于真实缓冲效果。
保留与新建了加工和动力区域的维修；没有通过无敌或自动修满全部甲板隐藏损伤。
可继续扩建甲板；本版预解锁了 256 块的科技容量，游戏本身仍有数量上限。

已验证
两艘船均通过完整连接、原生存档校验、全 16 种设备覆盖、WASD 合力平衡、Q/E 纯转矩和持续五分钟运行检查。
五分钟测试中 ARC 生产钢材 341、弹药 109、科研点 94，建造储备保留钢材 109。
LOOM 生产钢材 338、弹药 106、科研点 92，建造储备保留钢材 106。
分别使用实际建造储备和有限材料背包，成功各制作一件全部 16 种设备。
两种采矿设备的铁矿、石油、红石都通过实际输送与分类到达对应原料仓。
上述是隔离测试数据；实际运行时产量会随停机、航行、库存、编辑与输入变化。
